Potential bugs noticed while re-commenting the Eco compiler's Elm code
(src/, src-xhr/, tests/) with the elm-doc-comments workspace, run of 2026-10-03/04.

These were reported by the agents that mapped, commented, reviewed and reworked each
file. They have NOT been independently verified. Entries reported by several agents
(a commenting agent and its reviewer, say) are more likely to be real; an entry reported
once by the map reader alone was seen while reading for a summary, not while checking
a claim. Line numbers are against the baseline commit b86d3d3a, give or take the
lines added or removed by the comment changes. Reports within a few lines of each
other in the same file are merged and the longest description is kept.

Coverage is partial: the run stopped at the weekly usage limit with 178 files not yet
commented (most of src/Compiler beyond the AST, Type and Data layers), so bugs in those
files were seen only by the stage 02 map readers.

882 entries in 331 files.
