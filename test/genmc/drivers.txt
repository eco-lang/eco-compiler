#               NAME / NAME=VALUE   a -D define (driver variants, driver mutants MUTANT_*)

#               genmc:<flag>        an extra GenMC flag (every row runs -rc11)

#             by | (one weakened order can be reported either way, depending on the
#             execution GenMC reaches first):
#               assert:<expression>   a failed assert with that expression
#               race:<variable>       a data race; a racing event's variable as GenMC
#                                     names it (a prefix up to [ or . also matches)
#               race:@<code>          a data race; a racing event's source line
#                                     contains <code> (heap objects have no name in

#               uninit:<var|@code>    GenMC's "read from uninitialized memory": a
#                                     plain read of freshly allocated memory with no
#                                     initializing write visible to it, i.e. a race
#                                     with that write (AUDIT.md, "Tool facts")
