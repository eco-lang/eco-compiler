#   harness <name> <source dir> <cmake target>
#       a harness project, built with -DECO_TLA_TRACE=ON (g++, no TSan) into
#       build/tla-trace/<name>; it writes its raw log to $ECO_TLA_TRACE_OUT
#   trace <model> <dir> <module> <config> <harness> <args> <expected> [mutate=<m>]
#       args:     the harness arguments, comma-separated
#       expected: accept (TLC finds a behaviour matching the whole log) | reject
#       mutate:   a negative control: the same raw log, doctored before the merge
#                 (drop:<ev>:<k> | set:<ev>:<k>:<field>=<json> | swap:<ev>:<k>); it
#                 must be rejected, or the trace spec is too weak at that point
# A rejected `accept` row is a finding: a code defect (register) or a model error (AUDIT.md).
